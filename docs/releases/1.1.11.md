# Media File Renamer 1.1.11

This release makes batch review easier while preserving the app's existing look and transfer safeguards.

- Search filenames and titles, filter flagged rows, group TV episodes by show and season, and navigate directly through files needing attention.
- Compare highlighted filename changes and inspect full paths and companion-file destinations. Selected-file actions sit beside the comparison; narrow windows prioritize it and summarize staging options in an expandable panel.
- Confirm and next continues forward from the selected file. When review is complete, Show all files returns to the whole batch; Ready to move/copy describes readiness without implying a person inspected automatic matches.
- Re-match All repeats provider matching and offers a choice about replacing manual corrections. Kept manual TV choices stay protected during related-show updates.
- Clear batch offers restoration during the current session. Saved or cleared batches rescan sources and companions, recalculate destinations, and require fresh review before transfer.
- Completion feedback includes the destination, Undo, and cleanup details. Custom naming offers token insertion, a live example, and invalid-token feedback.

The Windows x64 ZIP is self-contained. Download its adjacent SHA-256 file to verify it. Existing installs can use the startup update prompt or Help → About → Check for updates.
