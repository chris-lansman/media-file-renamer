# Media File Renamer 1.1.0 acceptance record

Release-candidate acceptance completed on Windows on 2026-07-30 using the
self-contained Windows x64 application and synthetic media fixtures. Provider
checks used tester-owned credentials through the application UI; no credential
values are recorded here or in the acceptance artifacts.

## Passed gates

- Release build completed with zero warnings and formatting verification passed.
- All 161 automated tests passed under the .NET 10 Microsoft Testing Platform.
- Vulnerable and deprecated NuGet package audits reported no issues.
- The exact packaged candidate passed 52 UI checks at the active 125% display
  scale, including forward and reverse keyboard traversal, automation names,
  first-run Settings, local classification, history, recovery, and About.
- Settings and the main workflow passed constrained-window scrolling checks
  intended to exercise layouts at 200% effective size.
- A clean-profile first-run flow was exercised with an isolated data root.
- TMDB and TVDB connection tests passed using personal credentials.
- A real TMDB movie search returned `Blade Runner (1982)`.
- `Curious George` specials S00E07 and S00E08 resolved to the expected titles
  in the default order; an official-order probe confirmed TVDB fallback.
- Local copy, move, Undo, timestamp preservation, collision blocking,
  cancellation, crash recovery, and idempotent relaunch scenarios passed.
- Copy, move/Undo, network interruption, unavailable-share startup, and restored
  recovery scenarios passed against a uniquely named disposable SMB share.
- Provider acceptance found no credential values, authorization headers, or
  unredacted profile paths in the application logs.

## Scope notes

- The active desktop was tested at 125% display scaling. The automated layout
  suite also verifies constrained 200%-effective layouts, but mixed-monitor DPI
  movement was not available in this run.
- Full Narrator workflow certification is optional and was not used as a
  release gate. Keyboard-only use, meaningful automation names, theme resources,
  text/display scaling, and High Contrast resources remain automated gates.
- The release is an unsigned portable Windows x64 ZIP. Each user supplies their
  own TMDB and TVDB credentials; the package contains no provider credentials.
