# Media File Renamer 1.0.0 acceptance record

Release acceptance completed on Windows on 2026-07-24 using the packaged,
self-contained Windows x64 application and synthetic media fixtures. Provider
checks used tester-owned credentials through the application UI; no credential
values are recorded here or in the acceptance artifacts.

## Passed gates

- Release build completed with zero warnings.
- All 119 automated tests passed under the .NET 10 Microsoft Testing Platform.
- Formatting verification and vulnerable/deprecated NuGet package audits passed.
- Packaged UI flows passed at 100%, 150%, and 200% display scaling.
- High Contrast with 200% text size, keyboard navigation, automation names,
  onboarding, Settings scrolling, matching, history, recovery, and About passed.
- A clean-profile first-run flow was exercised with an isolated settings path.
- TMDB and TVDB connection tests passed using personal credentials.
- A real TMDB movie search matched `Blade Runner (1982)`.
- `Curious George` specials S00E07 and S00E08 resolved to the expected titles
  in the default order; a separate official-order probe confirmed TVDB fallback.
- Local copy, move, Undo, timestamp preservation, collision blocking,
  cancellation, crash recovery, and idempotent relaunch scenarios passed.
- Copy, move/Undo, network interruption, unavailable-share startup, and restored
  recovery scenarios passed against a uniquely named disposable SMB share.
- Provider acceptance found no credential values in the application logs.

## Scope notes

- Only one active display was available, so mixed-DPI monitor movement was not
  applicable. Each supported display scale was exercised directly.
- Full Narrator workflow certification is optional and was not used as a
  release gate. Keyboard-only use, meaningful automation names, High Contrast,
  and text/display scaling remain required accessibility checks.
- The release is an unsigned portable Windows x64 ZIP. Each user supplies their
  own TMDB and TVDB credentials; the package contains no provider credentials.
