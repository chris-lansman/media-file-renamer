# Media File Renamer 1.1.2 acceptance record

Release-candidate acceptance is performed on Windows using a self-contained
Windows x64 application and synthetic media fixtures. Provider checks use
tester-owned credentials through the application UI; no credential values are
recorded here or in the acceptance artifacts.

## Targeted regression

- `1987.Lethal.Weapon.1920x1080.BDRip.x264.DTS-HD.MA.mkv` parses as the movie
  `Lethal Weapon` from `1987`.
- Its exact title and year automatically select the matching TMDB movie
  candidate at 100% confidence.
- The real-provider acceptance workflow includes this filename and expects the
  `Lethal Weapon` (1987) movie candidate.

## Release gates

- Formatting, warning-free Release build, full automated test suite, NuGet
  audit, self-contained package smoke test, ZIP checksum verification, and
  GitHub Release publication must all pass before release handoff.
